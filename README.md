## ⌗ How to read an entry

| Column | Meaning |
|:-------|:--------|
| **Version** | The game/editor release the build belongs to, e.g. `24.30` |
| **Manifest** | The Epic manifest ID, e.g. `++Fortnite+Release-24.30` |
| **Archived builds** | One link per changelist (`CL`) — each links to that exact build on Drive. `↳` marks a fix that belongs to the build above it. |
